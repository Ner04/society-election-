🗳️ Society Election

Offline voting system
🗳️

Voting Booth

The screen voters use. Open on the booth computer, then press F11 / full screen.
🛠️

Admin Panel

Add voters & candidates, register faces, open/close voting, live counting, backups.
📺

Results Screen

For a TV or projector in the hall. Shows turnout live and results after closing.
Election day in 6 steps
  1. Admin Panel → create PINs → add teams & candidates → set vote weight per block (Settings) → add voters (or import from Excel CSV).
  2. Register each voter's face (camera or photo). Print voter slips with QR codes (optional).
  3. Do a trial run with committee members, then Settings → Reset all votes.
  4. On election morning: Dashboard → Open voting. Put the booth screen in full screen.
  5. Watch live turnout on the Dashboard. A polling officer helps anyone whose face isn't recognised (officer PIN).
  6. Close voting → print the result sheet → copy the data folder to a pen drive.
